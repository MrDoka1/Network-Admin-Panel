# Схема сети (001-initial-network-schema)

Описание таблиц и полей модели: устройства, интерфейсы, связи, VLAN, access/trunk.

Исходная миграция: `src/main/resources/db/changelog/changes/001-initial-network-schema.sql`.

---

## `network_device`

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | `uuid` | Стабильный идентификатор устройства во всех связях (интерфейсы, отчёты, API) без привязки к изменяемым именам или IP. |
| `device_type` | `varchar(32)` | Различать роль в сети (маршрутизатор vs коммутатор) для логики, отображения и правил конфигурации. |
| `hostname` | `varchar(255)` | Человекочитаемое имя в DNS/инвентаре и при отображении в UI; не заменяет технический `id`. |
| `mgmt_ip` | `varchar(64)` | Адрес, по которому администрируют устройство (SSH, SNMP, веб); хранится как строка, чтобы не завязываться на один формат (IPv4/IPv6). |
| `status` | `varchar(32)` | Показывает, учитывается ли устройство в эксплуатации (`ACTIVE`) или выведено из работы (`INACTIVE`), без удаления записи и истории связей. |

---

## `vlan`

| Поле | Тип | Описание |
|------|-----|----------|
| `vlan_id` | `smallint` | Номер VLAN в сети (802.1Q); как первичный ключ совпадает с тем, что видно на оборудовании и в конфигах. |
| `name` | `varchar(256)` | Описание назначения сегмента (например, офис, гости) для людей и документации. |
| `admin_status` | `varchar(32)` | Задуманное администратором состояние: VLAN разрешён к использованию (`ACTIVE`) или временно отключён (`SUSPENDED`). |
| `oper_status` | `varchar(32)` | Фактическое состояние на оборудовании (`UP` / `DOWN` / `UNKNOWN`) — для мониторинга и расхождений с админ-статусом. |

---

## `device_interface`

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | `uuid` | Уникальная ссылка на конкретный порт или LAG при создании линков и привязке VLAN; имя порта может дублироваться на разных устройствах. |
| `device_id` | `uuid` | Привязка интерфейса к владельцу-устройству; при удалении устройства каскадно убираются его порты. |
| `name` | `varchar(128)` | Имя в терминах оборудования (`Gi0/1`, `Ethernet1` и т.д.) — для сопоставления с реальной конфигурацией. |
| `admin_status` | `varchar(16)` | Включён ли порт административно (`UP` / `DOWN`) — отдельно от VLAN и от физического линка. |

---

## `link`

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | `uuid` | Идентификатор записи о соединении для API, журналов и ссылок из других сущностей. |
| `interface_a_id` | `uuid` | Один конец кабеля или логической связи — конкретный интерфейс. |
| `interface_b_id` | `uuid` | Второй конец связи; вместе с `interface_a_id` задаёт топологию L2 между устройствами. |

---

## `interface_vlan`

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | `uuid` | Технический ключ строки настроек VLAN на порту. |
| `interface_id` | `uuid` | Какой порт настроен; одна строка на интерфейс — единое место режима access/trunk. |
| `mode` | `varchar(16)` | Тип работы порта: один VLAN (`ACCESS`) или несколько с тегами (`TRUNK`). |
| `access_vlan_id` | `smallint` | В режиме access — единственный нетегированный VLAN для этого порта (клиентский порт). |
| `native_vlan_id` | `smallint` | В режиме trunk — VLAN для нетегированного трафика на этом trunk (native / PVID в терминах оборудования). |

---

## `trunk_allowed_vlan`

| Поле | Тип | Описание |
|------|-----|----------|
| `interface_id` | `uuid` | На каком trunk-порту задан список разрешённых VLAN. |
| `vlan_id` | `smallint` | Какой VLAN разрешён проходить через этот trunk (allowed list); пара с `interface_id` исключает дубликаты. |

---

## Связи и удаление

| От | К | Поведение при удалении |
|----|---|-------------------------|
| `device_interface.device_id` | `network_device.id` | `CASCADE` |
| `link.interface_a_id` / `interface_b_id` | `device_interface.id` | `CASCADE` |
| `interface_vlan.interface_id` | `device_interface.id` | `CASCADE` |
| `interface_vlan.access_vlan_id` / `native_vlan_id` | `vlan.vlan_id` | `RESTRICT` |
| `trunk_allowed_vlan.interface_id` | `device_interface.id` | `CASCADE` |
| `trunk_allowed_vlan.vlan_id` | `vlan.vlan_id` | `RESTRICT` |

`RESTRICT` на ссылки в `vlan` не даёт удалить VLAN, пока он используется в портах или в списке trunk. `CASCADE` от устройства к интерфейсам и от интерфейса к линкам упрощает удаление целого узла или порта из модели.
